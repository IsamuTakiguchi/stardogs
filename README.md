# STAR DOGS

ブラウザで遊べる3Dレールシューティングゲーム（Three.js製・1ファイル完結）。
遊撃隊スタードッグスのリーダー「ハヤテ」となり、ニャルガ帝国から惑星ポチテラを守る。

## グラフィック

- HDRレンダリング＋ブルーム、ACESトーンマッピング、リアルタイム影、空からの環境光・反射（PBRマテリアル）
- なめらかな曲面モデル（クリアコート塗装の自機・敵機・ボス）、起伏のある地形・海・渓谷、雲と遠景の山並み
- 炎・煙・火の粉・衝撃波の爆発、ウイングチップの飛行機雲、着水しぶき
- 重い端末では描画解像度を自動で下げる。ポストエフェクトを読み込めない環境では通常描画に切り替わる

## 遊び方

- ローカル：`npm start` → http://localhost:3000 （Node.js 18以上。依存パッケージなし）
- `public/index.html` を直接ブラウザで開いても遊べる（オフライン機能は http(s) で配信したときのみ有効）

## アプリとして使う（PWA）

https で配信したページを開き、ホーム画面に追加するとアプリとして全画面で起動する。

- iPhone / iPad（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「アプリをインストール」
- PC（Chrome / Edge）：アドレスバー右端のインストールボタン

一度開けばオフラインでも起動する（three.js は `public/vendor/` に同梱。フォントのみ Google Fonts から取得し、取れないときは端末のフォントで表示）。

## 公開（GitHub Actions → GitHub Pages）

`main` ブランチに push すると `.github/workflows/pages.yml` が `public/` を GitHub Pages に公開する（Actions タブから手動実行も可）。
公開URL：https://isamutakiguchi.github.io/stardogs/

初回だけ必要な設定：

1. リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にする
2. 非公開（private）リポジトリのままで Pages を使うには GitHub Pro 以上のプランが必要。無料プランの場合はリポジトリを公開（public）にする

デプロイごとにサービスワーカーのキャッシュ名が更新されるので、インストール済みのアプリも次回起動時に新しい版へ切り替わる。

## ステージ構成

平原 → 都市（屋上砲台）→ アーチ地帯（ミミ救出イベント）→ チェックポイント → 岩柱と機雷原 → 大編隊 → ボス「機動要塞ネコマタ」

- シルバーリング：シールド回復　／ ゴールドリング3つ：シールド最大値アップ（2回目以降は残機+1）
- 金色の敵機を落とすとアイテム（L：レーザー強化、B：ボム、S：シールド）
- ローリング中は敵弾をはじき返せる
