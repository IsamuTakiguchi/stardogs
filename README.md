# STAR DOGS

ブラウザで遊べる3Dレールシューティングゲーム（Three.js製・1ファイル完結）。
遊撃隊スタードッグスのリーダー「ハヤテ」となり、ニャルガ帝国から惑星ポチテラを守る。全2ステージ。タイトルの「出撃する」から星図（ルートセレクト）画面に進み、惑星を選んで発進する。

## グラフィック

- HDRレンダリング＋ブルーム、ACESトーンマッピング、リアルタイム影、空からの環境光・反射（PBRマテリアル）
- 空は大気の散乱（レイリー散乱・ミー散乱）を計算して描画。遠くほど空気でかすむ空気遠近法つき
- 地形は草地・岩肌・砂地のテクスチャを斜面と高さで塗り分け、崖は3方向投影で引き伸ばしを防ぐ。海は3層の波の法線で太陽を照り返す
- 宇宙は天の川・星雲・恒星の光芒、大気の縁が光る惑星、クレーターのある小惑星を描く
- なめらかな曲面モデル（クリアコート塗装の自機・敵機・ボス）、陰影のある積雲と遠景の山並み
- 炎・煙・火の粉・衝撃波の爆発、ウイングチップの飛行機雲、着水しぶき
- 重い端末では描画解像度を自動で下げる。ポストエフェクトを読み込めない環境では通常描画に切り替わる

## サウンド

BGMはすべてオリジナル曲で、録音データを使わずブラウザ内でリアルタイムに合成している。

- ステージ曲：金管ファンファーレの前奏からAメロ→サビを繰り返す、ニ短調・テンポ150の宇宙戦マーチ
- ステージ2曲：アルペジオが疾走するイ短調・テンポ140のスペースマーチ
- ボス曲：低音の金管と16分刻みのベースで迫る、ホ短調・テンポ166
- クリア／ゲームオーバーのジングル
- 音源：デチューンした金管、ストリングス、歪ませたベース、アルペジオ、ティンパニ、ロックドラム。ホール残響とコンプレッサーを通して鳴らす

## ボイス

無線のセリフ（コテツ隊長・ミミ・チップ・ゲルニャ司令、全62本）はキャラクターごとの声で読み上げる。声が流れている間はBGMを少し下げ、顔グラフィックの口が声に合わせて動く。タイトルの「ボイス」のチェックを外すと声だけ消せる。

- 声は音声合成モデル [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)（Apache-2.0）で事前に作った音声ファイル（`public/voice/`、計約1.3MB）。端末の読み上げ機能は使わないので、どの端末でも同じ声になる
- セリフを追加・変更したら `tools/voice/` のスクリプトで作り直す：
  1. `python tools/voice/extract_lines.py lines.json`（ゲーム内のセリフを抜き出す）
  2. `python tools/voice/gen_voice.py lines.json`（足りない音声だけ作る。キャラの声質と読み方の補正はスクリプト冒頭の `CAST` と `SAY`）
  - 必要なもの：Python 3.10以上、`pip install torch kokoro "misaki[ja]" soundfile`、`python -m unidic download`、ffmpeg（rubberband 対応）

## 遊び方

- ローカル：`npm start` → http://localhost:3000 （Node.js 18以上。依存パッケージなし）
- `public/index.html` を直接ブラウザで開いても遊べる（オフライン機能は http(s) で配信したときのみ有効）

## 操作

ロブロックスと同じ感覚で、左手で移動・右手で攻撃する。

| 操作 | タブレット・スマホ | キーボード・マウス | ゲームパッド |
| --- | --- | --- | --- |
| 移動 | 画面左半分をドラッグ（スティックが指についてくる） | WASD / 矢印 | 左スティック |
| ショット | 右下の大きいボタン | Space / 左クリック | A / RT |
| ボム | ボムボタン | E | B |
| ローリング（敵弾をはじく） | ロールボタン | Q | X / LB / RB |
| ブースト | なし | Shift | LT |
| ポーズ | 上の II ボタン | Esc / P | START |

ショットは押しっぱなしで連射。そのまま押し続けて照準が黄色になったら離すと、ロックオン弾が敵を追いかける。

## アプリとして使う（PWA）

https で配信したページを開き、ホーム画面に追加するとアプリとして全画面で起動する。

- iPhone / iPad（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「アプリをインストール」
- PC（Chrome / Edge）：アドレスバー右端のインストールボタン

一度開けばオフラインでも起動する（three.js は `public/vendor/` に同梱。フォントのみ Google Fonts から取得し、取れないときは端末のフォントで表示）。

## 公開（GitHub Actions → GitHub Pages）

`main` ブランチに push すると `.github/workflows/pages.yml` が `public/` を GitHub Pages に公開する（Actions タブから手動実行も可）。
公開URL：https://isamutakiguchi.github.io/stardogs/

初回だけ必要な設定：

1. リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にする
2. 非公開（private）リポジトリのままで Pages を使うには GitHub Pro 以上のプランが必要。無料プランの場合はリポジトリを公開（public）にする

デプロイごとにサービスワーカーのキャッシュ名が更新されるので、インストール済みのアプリも次回起動時に新しい版へ切り替わる。

## ステージ構成

**STAGE 1　惑星ポチテラ**：海 → 平原 → 都市（屋上砲台）→ アーチ地帯（ミミ救出イベント）→ チェックポイント → 岩柱と機雷原 → 大編隊 → ボス「機動要塞ネコマタ」

**STAGE 2　マタタビ小惑星帯**：小惑星帯（岩をよけながら戦う）→ チップ救出イベント → チェックポイント → 敵艦隊の甲板すれすれを飛ぶ艦隊戦（砲台・格納庫から出撃する敵機）→ ボス「宇宙空母クロネコ」（砲台4基を壊すと艦首のコアが開く。薙ぎ払いビームに注意）

ステージ1をクリアするとリザルト画面の「次のステージへ」でそのままステージ2へ進める。ベスト記録はステージごとに保存される。

### ルートセレクト（ステージ選択）

星図の上に惑星ポチテラ → マタタビ小惑星帯 → ニャルガ本星（未開放）が航路で結ばれ、自機が選んだ惑星まで航路をたどって飛んでいく。右下（スマホでは下）のパネルにエリア・ボス・ベスト記録・ランクと、コテツ隊長のブリーフィングが表示される。クリアした惑星には CLEAR が付き、次の惑星への航路が金色に変わる。

| 操作 | タブレット・スマホ | キーボード | ゲームパッド |
| --- | --- | --- | --- |
| 惑星を選ぶ | 惑星をタップ／◀ ▶ | ← → ↑ ↓ / WASD | 十字キー・左スティック |
| 発進 | 選んだ惑星をもう一度タップ／発進！ | Enter | A |
| 戻る | 戻る | Esc | B |

- シルバーリング：シールド回復　／ ゴールドリング3つ：シールド最大値アップ（2回目以降は残機+1）
- 金色の敵機を落とすとアイテム（L：レーザー強化、B：ボム、S：シールド）
- ローリング中は敵弾をはじき返せる
